## Plain Language 强制规则（写完大声读一遍，像规格说明书就重写）

| 不要写 | 改成 |
| --- | --- |
| "系统处理请求" | "App 完成 [姓名] 让它做的事" |
| "用户进行身份验证" | "[姓名] 登录" |
| "可配置参数" | "[姓名] 可以改的设置" |
| "AI 生成响应" | "助手回复" |
| "持久化数据" | "下次 [姓名] 打开还在" |

## 自检（不通过就重写）
1. 一个 Story 写成两个？完成标准里"且/同时"超过 2 次 → 拆
2. 完成标准是不是 [姓名] 能直接看到/做到的？出现"系统记录/后台同步" → 重写
3. 设计触点空或太宽泛？写"需要一些屏" → 不通过
4. 关联策略维度有没有填
5. JTBD 公式能不能套进这个 Story
