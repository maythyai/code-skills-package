# 反向验证完整协议（因子权重的经验校准）

## 核心理念

初始权重是假设，必须用实际调研结果反向验证。当积累了一定数量的 L4 深度调研样本后，可以用实际分层/评分结果倒推各因子的真实预测力，取代拍脑袋设定的权重。

## 触发条件

完成首批 L4 深度调研（通常 10-20 家）后，即应启动反向验证。

## 操作步骤

### 步骤 1：计算各因子在不同层级的浓度分布

```
对每个因子（如"管理层态度"），统计其各取值在 A/B/C 层的分布：

因子 X 取值 Y 在 A 层的浓度 = A 层中因子 X=Y 的公司数 / A 层总数
因子 X 取值 Y 在 C 层的浓度 = C 层中因子 X=Y 的公司数 / C 层总数

浓度差 = A 层浓度 - C 层浓度
浓度差越大 → 该因子该取值的区分力越强
```

### 步骤 2：排序并确定权重

按浓度差大小排序所有因子，浓度差最大的因子获得最高权重。典型输出格式：

```
| 排名 | 因子 | 权重 | A 层浓度 | C 层浓度 | 浓度差 | 独立区分度 |
|------|------|------|---------|---------|--------|------------|
| 1 | XX | 30% | 57% | 0% | 57% | 极强 |
| 2 | YY | 20% | 71% | 9% | 62% | 强 |
| ... | ... | ... | ... | ... | ... | ... |
```

### 步骤 3：模型预测 vs 实际结果对照

对每家已完成 L4 的公司，用权重公式计算"预测评分"，与实际 L4 评分对比：

```
| 公司 | 模型预测 | 实际 L4 评分 | 偏差 | 偏差原因 |
|------|---------|-------------|------|----------|
```

计算吻合率：

- 完全吻合（偏差 ≤ 0.5 分）
- 轻微偏差（0.5-1 分）
- 严重偏差（> 1 分）

目标：完全吻合率 ≥ 70%，严重偏差率 = 0%。

### 步骤 4：偏差分析与权重修正

对每个偏差案例分析根因：

- 是否有 L2 阶段遗漏的信息？
- 是否某个因子在特定组合下含义不同？
- 是否需要新增/删除因子？

基于偏差分析修正权重参数，产出"因子权重 v2.0"。

## 模型局限性识别

反向验证还应产出"模型无法覆盖的维度"清单——这些维度必须依赖人工判断补充：

```
| 维度 | 为什么模型无法覆盖 | 人工判断方法 |
|------|-------------------|------------|
| 创始人性格 | 公开信息无法获取 | 首次会面直接感受 |
| 内部预算真实规模 | 几乎不公开 | 线下 BD 探询 |
| ... | ... | ... |
```
