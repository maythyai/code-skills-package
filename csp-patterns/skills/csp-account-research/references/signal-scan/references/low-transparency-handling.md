# 低信息透明度行业的评估规范

## 核心原则

保密文化强的行业（金融、军工、部分制造业）中，"信息缺失"不等于"没有需求"。需采用差异化评估策略。

## 透明度分级与处理策略

| 透明度等级 | 判定标准 | 评分策略 | 后续动作 |
|-----------|---------|---------|---------|
| 高 | 深度报道 ≥ 3 篇，管理层主动公开 | 正常评分 | 标准流程 |
| 中 | 有基本信息，偶有发言 | 正常评分，缺失维度标 0 分 | 标准流程 |
| 低 | 公开细节极少，管理层极少发言 | **不对缺失维度过度扣分** | 标注"需线下 BD 补充" |
| 极低 | 几乎无公开信息 | 仅评可获信息，做双轨估计 | 标注"无法远程评估" |

## 双轨评估法（适用于低/极低透明度）

对低透明度公司，同时做两个假设：

```
保守假设：所有缺失信息按"不利"处理 → 得出最低可能评分
乐观假设：缺失信息按"同行业同规模平均值"处理 → 得出合理预期评分

最终标注格式：
  评分区间：[保守 2.5 分 - 乐观 4.0 分]
  建议：需线下 BD 验证后才能确定最终分层
```

## 行业特殊处理

- **金融/资管行业**：普遍低透明度是行业特征，不应因此降低整体评估预期
- **制造业**：技术信息通常可通过专利数据库获取，"低透明"主要指商业信息
- **互联网**：如果互联网公司也信息极少，往往暗示"体量小"或"即将关闭"
