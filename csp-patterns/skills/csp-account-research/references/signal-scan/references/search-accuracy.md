# 搜索准确性保障与异常名称处理

## 分层搜索策略

### 第 1 层：标准名称搜索（预期命中率 80%+）

- 搜索次序：中文法定名 → 英文名 → 常用简称
- 命中标准：≥ 3 个独立信息源确认公司身份

### 第 2 层：异常名称处理（第 1 层失败时触发）

1. 音形相近名称搜索（针对 OCR 错误或笔误）
2. 关联主体搜索（通过创始人/投资方反查）
3. 工商备案反查（企查查/天眼查按条件搜索）
4. 行业渠道验证（协会网站、行业人脉确认）

## 跨信息源名称统一

| 信息源 | 优先级 | 使用规则 |
|--------|--------|---------|
| 工商备案/融资 DB | 一级 | 作为"标准名" |
| 官网/新闻 | 二级 | 搜索时同时使用 |
| 招聘平台 | 三级 | 需交叉验证 |

## 搜索质量指标

```
搜索命中率 = 成功定位家数 / 名单总家数
  目标：≥ 95%

异常处理转化率 = 异常流程成功定位数 / 第 1 层失败数
  目标：≥ 60%
```

## 质量检查清单

- [ ] 所有无结果的公司是否都执行了第 2 层异常处理？
- [ ] 每家公司是否有 ≥ 2 个独立信息源确认身份？
- [ ] 是否建立了"名称统一映射表"？
- [ ] 所有"信息缺失"是否标注了缺失原因？
