# 因子组合交叉分析方法论

## 核心认知

单一因子的预测力有限，**因子组合**才是真正的预测驱动力。某些组合的命中率可达 100%，远高于任何单因子。

## 操作方法

### 步骤 1：枚举关键组合

从最高权重因子开始，两两/三三组合：

```
正向组合（指向高优先级）：
- 第 1 因子强 + 第 2 因子强 → 检查 A 层命中率
- 第 1 因子强 + 第 3 因子强 → 检查 A 层命中率
- 第 1 因子强 + 第 2 因子强 + 第 4 因子强 → 检查 A 层命中率

负向组合（指向低优先级）：
- 第 1 因子弱 + 第 2 因子弱 → 检查 C 层命中率
```

### 步骤 2：计算组合命中率

```
组合命中率 = 满足该组合条件的 A 层公司数 / 满足该组合条件的全部公司数

若命中率 ≥ 90% → 该组合为"强正向预测子"
若命中率 ≤ 10% → 该组合为"强负向预测子"
```

### 步骤 3：产出"组合速查规则"

将命中率 ≥ 90% 的组合固化为快速筛选规则：

```
[强正向] 因子 A=激进 + 因子 B=高 → 100% 为高优先级
[强正向] 因子 A=激进 + 因子 C=强 + 因子 D=高 → 100% 为高优先级
[强负向] 因子 A=缺失 + 因子 C=弱 → 0% 为高优先级
```

## 非线性效应识别

交叉分析的核心价值在于发现"非线性效应"——同一因子在不同组合下含义完全不同：

```
示例：因子 A（管理层态度）= 激进
├─ 当因子 B（外采倾向）= 高 → deal size 最大、成单最快
├─ 当因子 B（外采倾向）= 低 → 技术实力强但难切入
└─ 单独看因子 A 无法区分这两种完全不同的商业含义
```

此类发现应记录为"非线性规则"，在后续 L2 扫描评分时作为修正依据。
