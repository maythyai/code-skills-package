# Quality Checklist（L2 信号扫描自检清单）

本清单在每批 L2 扫描完成时由 Agent 自动执行，并写入 `L2_scan/quality_check.md`。

## 名单与搜索质量

- [ ] 公司名单已通过工商名称校验（参考 ../../shared/phase-1-pool-construction.md）
- [ ] 第 1 层标准名搜索覆盖率记录在案
- [ ] 第 1 层失败的公司全部走过第 2 层异常处理（参见 [search-accuracy.md](./search-accuracy.md)）
- [ ] 搜索命中率 ≥ 95%
- [ ] 异常处理转化率 ≥ 60%

## 维度覆盖

- [ ] 13 维度全部按模板执行（行业适配后的维度组合已在 brief.json 锁定）
- [ ] 业务规模指标（D7）按行业代入正确口径（AUM/ARR/营收/装机量等）
- [ ] 每家公司至少使用 3 类独立信息源
- [ ] 每个维度评分都附证据 URL/出处
- [ ] 所有证据都标注了查阅时间或发布时间（参见 [info-decay.md](./info-decay.md)）
- [ ] 每家公司是否同时使用了中文和英文搜索？国内公司中文为主但英文不可省，海外公司英文为主但中文不可省

## 评分一致性

- [ ] 标准样本已锁定（2-3 家，每维度有详细打分理由）
- [ ] 每批完成后用 1-2 个标准样本对标
- [ ] 批次间差异系数 < 10%
- [ ] 边界公司（阈值 ±2 分）已做二次搜索确认

## 数据规范

- [ ] CSV 输出符合五层字段架构（参见 [data-schema-design.md](./data-schema-design.md)）
- [ ] 编码为 UTF-8 with BOM
- [ ] 缺失值用空字符串表示（不用 "N/A"/"未知"）
- [ ] `关键证据摘要` 字段填充率 100%

## 分层结果

- [ ] A/B/C/信息缺失四层均有数量统计
- [ ] 各层典型代表分析已产出
- [ ] 边界公司说明（为什么判 A 不判 B）已产出
- [ ] 信号分布热力图（哪些维度普遍得分高/低）已产出

## 反模式排查

- [ ] 未触发 SS-1 到 SS-10 任何反模式（参见 [anti-patterns.md](./anti-patterns.md)）
- [ ] 所有"信息缺失"标注了缺失原因
- [ ] 低透明度行业是否启用了双轨评估法（参见 [low-transparency-handling.md](./low-transparency-handling.md)）

## 行业适配确认

- [ ] 已识别并锁定本行业第一决定因子
- [ ] 13 维度的行业微调已记录在 brief.json 中
- [ ] 若已积累 L4 数据，已启动反向验证（参见 [reverse-validation.md](./reverse-validation.md)）
