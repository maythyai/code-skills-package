# 攻坚路径：三层递进模型

每个客户的攻坚建议应遵循「建立信任 → 扩大范围 → 深化合作」的递进结构，而非一次性推荐所有产品。

## 第一步：建立信任（30-45 天）

**目标**：在不触及客户核心系统的前提下，快速证明价值。

产品选择原则：

- 不接管客户核心业务系统
- 不依赖复杂数据迁移
- 有明确的 30 天 PoC 方案
- 支持免费试用或低成本试验

**成功指标**：

- 用户主动正向反馈
- 内部有人因此产品获得可感知收益
- 客户愿意进行第二个产品试用

## 第二步：扩大范围（45-90 天）

**触发条件**：第一步 PoC 完成且获得正反馈。

产品选择原则：

- 与第一步产品有协同性（非竞争关系）
- 服务不同部门或场景（非重复功能）
- 能与第一个产品形成相互补强

**成功指标**：

- 第一个产品有试付款或小额采购
- 两个产品的协同效应被认可
- 客户内部多个部门参与体验

## 第三步：深化合作（6-12 个月后）

**触发条件**：前两个产品都有实际付费和续约意向。

产品特征：

- 高价值产品或专业服务
- 需要充分信任积累
- 涉及较大采购额或长期合同

## 按画像类型的递进方案

| 画像 | 第一步（信任） | 第二步（扩展） | 第三步（深化） |
|-----|-------------|-------------|-------------|
| A 型（激进采购） | 生产力工具 | 统一管理平台 | 企业定制 / 安全合规 |
| B 型（学术先锋） | 效率工具（定位「增强」非「替代」） | API 管理（减轻工程负担） | 学术合作 / 专属订阅 |
| C 型（爆发新锐） | 快速交付基建工具 | 自动化运维 / 成本优化 | 深度定制化方案 |
| D 型（务实转型） | ROI 明确的单点工具 | 与现有系统集成 | 整体数字化转型 |
| E 型（自闭壁垒） | 极低风险工具类（唯一切入点） | 需等待组织变化信号 | 重新评估 |

## 递进失败时的备选方案

第一步未能成功（30 天无正反馈或客户暂停）时：

1. **诊断根因**：产品不匹配？体验差？优先级变化？组织变化？
2. **调整策略**：换产品方案 / 改进交付支持 / 暂时搁置监测信号
3. **备选路径**：转为「长期关系维护」模式（月度接触，监测升层信号）

## 在交付物中的应用

D1 客户卡片的「攻坚路径建议」必须按三步给出，且每一步必须有明确的「成功指标」和「失败回退」。
