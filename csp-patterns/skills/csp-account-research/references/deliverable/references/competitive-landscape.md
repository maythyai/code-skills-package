# 竞争格局：相对势能分析

## 核心理念

竞争分析不应停留在「列出竞对名称」，而应分析各方的「相对势能」——即在目标客户群中，各竞争者的结构性优劣势。

## 厂商范围（写死）

- **竞对厂商**：竞对厂商（brief.json 配置）
- **我方厂商**：我方产品

下文所有「竞对」「我方」均指上述厂商。

## 五力分析在 B2B 技术销售中的应用

| 力量 | 分析要点 | 对销售策略的影响 |
|-----|---------|---------------|
| 买方议价能力 | 客户是否有多个替代选择？采购决策层级？ | 高 → 定价空间有限，侧重增值服务 |
| 供应商议价能力 | 我方是否有独占资源（如独家模型、专有数据） | 高 → 可议价空间大，强调差异化 |
| 新进入者威胁 | 行业信任壁垒高低？切换成本？ | 低 → 竞争格局稳定，深耕存量 |
| 替代品威胁 | 自建方案的可行性？开源替代的成熟度？ | 高 → 需强调「非替代优势」 |
| 现有竞对强度 | 竞对的行业深度和客户关系密度？ | 高 → 差异化定位，避免正面竞争 |

## 相对势能评估模板

对每个目标行业，填写：

```
我方相对势能 =
  (供应商议价能力 + 进入壁垒保护)
  - (买方议价能力 + 替代品威胁 + 竞对强度)

正值 → 有结构性优势，可积极进攻
零值 → 势均力敌，需差异化竞争
负值 → 结构性劣势，需战略性选择细分市场
```

## 竞对单家分析模板

每家竞对（竞对厂商（brief.json 配置））必须填齐以下字段：

| 字段 | 说明 |
|------|------|
| 在目标行业的客户家数 | 基于 L2/L4 数据汇总 |
| 在目标行业的渗透率 | 按家数 + 按业务规模加权两个口径 |
| 典型胜出场景 | 该竞对在哪类客户类型上胜率高 |
| 典型失败场景 | 该竞对在哪类客户类型上胜率低（即我方机会） |
| 差异化壁垒 | 该竞对独有的核心能力 |
| 价格策略 | 标杆价格 / 折扣策略 |
| 关键合作伙伴 | 与该竞对深度绑定的渠道 / 集成商 |

## 我方产品的定位

回答以下三个问题，作为 D4 / D1 的核心论据：

1. 我方产品的结构性优势在五力中的哪些位置？
2. 客户选择我方产品而非竞对厂商（brief.json 配置）的理性理由是什么？
3. 在哪些细分场景上，我方产品相对势能为正？

## 在交付物中的应用

- D4 行业市场洞察的「竞争格局」章节以本文档为骨架
- D1 TOP 卡片的「竞对威胁评估」必须按本文档单家模板展开
- 不允许仅写「X 厂商是主要竞对」这类无支撑论断
