# D2：高管摘要

**目标读者**：C-Level / VP
**篇幅**：300-500 字（不含标题）；阅读时长 ≤ 3 分钟

## 写作原则

C-Level / VP 注意力窗口极短，高管摘要必须在 3 分钟内读完，核心发现在前 30 秒即可获取。

## 结构模板（严格顺序）

```markdown
# [30秒电梯演讲]
—— 一句话说清「市场多大 + 我们在哪 + 应该怎么做」

## 核心发现（3条，每条≤30字）
1. [**市场规模**] ...
2. [**空白机会**] ...
3. [**竞对态势**] ...

## 推荐行动（3条，每条含时间约束）
1. 立即做：...
2. 30天内：...
3. 本季度：...

## 资源投入建议（1-2句）
[N人 × N个月] 专注 [X 家客户]，预期产出 [Y 万元 pipeline]
```

## 写作规范

1. **总篇幅**：严格控制在 300-500 字（不含标题）
2. **30 秒电梯演讲**：必须是一个完整句子，包含「市场规模 + 我方位置 + 建议方向」三个要素
3. **核心发现**：每条必须是「反直觉」或「可量化」的——禁止「市场很大」「竞争很激烈」等废话
4. **推荐行动**：每条必须含时间约束和可验证结果，禁止「建议加强客户关系」这类无法衡量的建议
5. **数字先行**：每个核心观点尽量用数字支撑（如「空白市场 50 家」而非「市场空间很大」）
6. **禁止信息过载**：不包含具体公司名单、不展开方法论、不贴数据表格

## 与其他交付物的衔接（强制）

高管摘要是「入口文档」，**必须在每个核心发现块后标注「详见 [文档名] §X」**，引导读者下钻到主文档。禁止在本摘要中展开以下内容：

| 禁止展开的内容 | 应引用的主文档 | 说明 |
|--------------|-------------|------|
| TOP 10 公司完整清单 | D1 §2.1 | 摘要只放速查表，完整画像/决策人/联系方式见 D1 |
| 具体 deal size 公式/参数 | D1 §使用须知 | 摘要只引用 SOM 数字，不展开推导 |
| 客户分型方法论（A/B/C/D/E） | D1 §1.2 | 摘要只提"5 种画像"，不展开每型定义 |
| 产品功能详细对比 | D3 | 摘要只提"首推 我方产品"，不展开产品矩阵 |
| 竞对每家渗透详情 | D4 §4 | 摘要只提"竞对渗透 7%"，不展开每家 |
| 方法论/调研流程 | D1 §使用须知 | 摘要不解释"怎么调研的" |

### 去重自检（生成后逐项核对）

- [ ] 本摘要内部是否存在同一观点换说法重复的情况？（严禁）
- [ ] 本摘要中的关键数字是否与 D1/D4 中的同一数字一致？
- [ ] 是否在本摘要中展开了应在 D1/D3/D4 中详述的内容？如发现则精简为一句话 + 「详见」引用

## 反例（必须规避）

| 反例 | 问题 | 正确写法 |
|------|------|---------|
| 「市场前景广阔」 | 无量化 | 「行业 IT 投入 N 亿，AI 占比 X%」 |
| 「建议加强客户关系」 | 无时间无可验证项 | 「30 天内完成 TOP5 客户首次拜访」 |
| 含具体 10 家公司清单 | 信息过载 | 「TOP10 详见 D1」 |
| 含完整方法论 | 越界 | 「方法论详见 D1 使用须知」 |
