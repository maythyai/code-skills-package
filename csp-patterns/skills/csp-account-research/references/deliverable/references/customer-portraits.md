# 五维度客户画像库与分类规则

在生成交付物前，应先对所有客户进行五维度分类，为产品匹配和攻坚策略奠定基础。

## 五维度框架

| 维度 | 选项 |
|-----|------|
| 管理层技术态度 | 激进型 / 务实型 / 保守型 / 缺失型 |
| 自建能力 | 极强（年投入 > 5000 万，完全自研） / 中等 / 弱 / 无 |
| 外采倾向 | 高（云原生，明确外采计划） / 中（混合架构） / 低（全自建） / 缺失 |
| 增长动能 | 爆发（业务规模增速 > 50%） / 稳健（15-50%） / 平稳（< 15% 或下降） |
| 信息透明度 | 高（深度报道 ≥ 3 篇） / 中 / 低（公开细节极少） |

> 业务规模增速按行业代入对应口径：AUM 增速（量化私募/资管）/ ARR 增速（SaaS）/ 营收增速（通用企业）/ 装机量增速（制造业）/ 用户数增速（互联网）。

## 五类标准画像

| 画像 | 态度 | 自建 | 外采 | 增速 | 核心诉求 | 年 deal 预期 | 成单周期 |
|-----|------|------|------|------|---------|-----------|----------|
| **A 型：激进采购** | 激进 | 无/弱 | 高 | 任意 | 快速集成、生产力提升 | 400-2500 万 | 2-6 个月 |
| **B 型：学术先锋** | 激进 | 中强 | 低 | 任意 | 技术深度、创新赋能 | 300-2000 万 | 3-6 个月 |
| **C 型：爆发新锐** | 任意 | 弱中 | 中 | 爆发 | 快速交付、规模化 | 150-800 万 | 1-3 个月 |
| **D 型：务实转型** | 务实 | 强 | 中 | 稳健 | ROI 明确、风险可控 | 200-1000 万 | 3-6 个月 |
| **E 型：自闭壁垒** | 任意 | 极强 | 极低 | 任意 | 极细分场景或工具 | 0-30 万 | 6-12+ 月 |

> 上述 deal 预期数字为示例区间，实际值需结合 [roi-estimation.md](./roi-estimation.md) 公式按行业代入计算。

## 分类判定流程

```
START
├─ 有明确 AI/技术创新部门？
│  ├─ 是 → 年 IT 投入 > 5000 万且完全自建？
│  │  ├─ 是 → B 型（学术先锋）
│  │  └─ 否 → A 型（激进采购）
│  └─ 否 → 业务规模增速 > 50%？
│     ├─ 是 → C 型（爆发新锐）
│     └─ 否 → IT 投入 > 5000 万 或 IT 团队 > 100 人？
│        ├─ 是 → D 型（务实转型）
│        └─ 否 → E 型（自闭壁垒）
END
```

## 画像与 L2 分层的关系

注意：五类画像与 L2 分层（A/B/C 层）是两个正交维度：

- L2 分层侧重「与我方产品的匹配度」（信号强度）
- 五类画像侧重「客户的组织特征与决策模式」

建议在交付物中同时标注两个维度：

```
客户名称：XX 公司
├─ L2 分层：A 层（信号强度高）
├─ 五类画像：D 型（务实转型）
├─ 产品匹配：中等，侧重增量
└─ 建议攻坚周期：3-6 个月
```

## 边界情形处理

| 情形 | 处理方式 |
|------|---------|
| 维度数据缺失 ≥ 2 项 | 画像标注为「待补充」，不进入 TOP 卡片 |
| 自建能力「极强」但工具链需求「高」 | 按 [d3-product-matrix.md](./d3-product-matrix.md) 三场景拆分重判 |
| 业务规模增速口径无数据 | 用同业平均值标 [A] Analogy 标签 |
