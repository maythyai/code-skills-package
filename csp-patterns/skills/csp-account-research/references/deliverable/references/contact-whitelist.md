# 联系方式采集白名单

## 原则

反编造第一原则：**搜得到的才写，搜不到的标 `[需人工核实]`**。禁止用大模型训练数据中的默认知识（如"知名公司默认电话 400-xxx"）填充联系方式字段——这是安全风险极高的幻觉。

## 四级采集顺序（硬约束）

按以下顺序逐级搜索，上一级搜到即停止：

| 优先级 | 来源 | 搜索方式 | 可靠性 | 说明 |
|--------|------|---------|--------|------|
| 1 | **基金业协会 / 监管备案公示** | web 搜索 "公司全称 基金业协会" + fetch `amac.org.cn` 公示页 | 最高 | 法定备案信息：公司主体、备案号、注册地址、法定代表人 |
| 2 | **公司官网联系页** | web 搜索 "公司官网" → 打开 → fetch `/contact` 或 `/联系我们` 子页 | 高 | 业务联络电话、媒体邮箱、办公地址。注意 JS 渲染官网 fetch 可能失败，此时从搜索结果 snippet 间接获取 |
| 3 | **工商登记（天眼查 / 企查查）** | web 搜索 "公司全称 天眼查" 或 "公司全称 企查查" | 高 | 法定注册地址、法定代表人、注册资本、成立日期 |
| 4 | **正规财经媒体署名报道** | web 搜索 "公司名 电话" / "公司名 邮箱" 筛选可靠媒体来源 | 中 | 记者署名稿件中的联系方式。不采信自媒体、论坛帖子 |

### 补充源

- **校招页 / 招聘 JD**：可作为企业邮箱（如 `hr@xxx.com`、`jobs@xxx.com`）的补充来源
- **创始人采访 / 公开演讲**：可补充公司主体确认和管理层信息
- **行业会议资料**：可补充业务联络方式

## 每条联系方式的输出格式

无论采集到哪一级，每条信息必须挂来源标签：

```
电话：021-61639672 [来源: 官网]
邮箱：media@wizardquant.com [来源: 官网]
备案号：P1016966 [来源: 基金业协会公示]
公司主体：上海念空私募基金管理合伙企业（有限合伙）[来源: 企查查]
```

### 三级交叉验证（建议，非强制）

对高价值客户（TOP 10），建议使用 web 搜索 + fetch 官网 contact 页 + 工商页三向比对。至少两个独立来源一致才标注为 [确认]，仅单源标注为 [弱推断]。

## [需人工核实] 标注规范

以下情况统一标注 `[需人工核实]`：

1. 四级来源全部搜不到电话或邮箱
2. 公司官网无法访问且无工商登记
3. 搜索到的号码可能是代理/中介而非公司直连
4. 公司主体存疑（如名字可能与其他公司混淆）

**举例**：
```
电话：[需人工核实]
邮箱：[需人工核实]
```
不要留空字段——空字符串对读者意味着"忘填了"，`[需人工核实]` 意味着"确实查不到，需要你线下确认"。

## 来源标签体系

可与交付物可靠性标签（[确认]/[强推断]/[弱推断]/[信息缺失]）并行使用：

| 来源标签 | 含义 | 采集优先级对应 |
|---------|------|---------------|
| [来源: 基金业协会公示] | 中基协 amac.org.cn 备案信息 | 优先级 1 |
| [来源: 官网] | 公司官方联系页 | 优先级 2 |
| [来源: 企查查] | 工商登记信息 | 优先级 3 |
| [来源: 天眼查] | 工商登记信息 | 优先级 3 |
| [来源: 媒体] | 正规财经媒体署名报道 | 优先级 4 |
| [来源: 校招页-媒体] | 校园招聘页面或招聘平台 JD | 补充源 |
| [需人工核实] | 四级来源无法确认 | 缺失 |
