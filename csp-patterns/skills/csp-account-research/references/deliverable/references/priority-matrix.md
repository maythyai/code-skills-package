# 客户优先级的矩阵定位法

## 核心理念

简单的 TOP 排名（1-10 名）容易掩盖市场的结构性特征。应绘制「切入难度 × 商业价值」二维矩阵，揭示战略位置。

## 二维矩阵框架

```
商业价值（纵轴）
  高 │  ③高壁垒高价值    │  ①理想标的
     │  策略：长期监测     │  策略：集中攻坚
     │                    │
  中 │  ④性价比低         │  ②快速突破
     │  策略：暂不投入     │  策略：打造标杆
     │                    │
  低 │                    │
     └────────────────────────────
         高 ←── 切入难度 ──→ 低
```

## 四象限的策略含义

| 象限 | 特征 | 资源投入建议 | 典型销售动作 |
|-----|------|------------|------------|
| ① 理想标的 | 高价值 + 低难度 | 最高优先级，集中资源 | 快速推进 PoC → 签约 |
| ② 快速突破 | 中价值 + 低难度 | 优先打造标杆案例 | 快速签约 → 做成案例传播 |
| ③ 高壁垒高价值 | 高价值 + 高难度 | 长期关系维护，不急投入 | 月度接触，等待窗口 |
| ④ 性价比低 | 低价值 + 高难度 | 不建议投入 | 仅维持最低触达 |

## 结构性发现

实际调研中通常会发现一个关键规律：**几乎不存在「高价值 + 低难度」的甜蜜点**。

原因：高价值客户通常体量大、决策复杂、竞对覆盖密集，天然就是高壁垒。

这意味着：

- 不要在「理想标的」象限花时间找——很可能不存在或极少
- **真正的战略重点在 ② 象限**：找到中等价值但容易突破的客户，快速打造标杆
- 标杆案例建成后，用它撬动 ③ 象限的高壁垒客户

## 矩阵定位的量化方法

### 商业价值评分（0-10 分）

```
= deal size 预期（0-4 分）+ 战略价值（0-3 分）+ 复购/扩展潜力（0-3 分）

deal size：> 1000 万 = 4，500-1000 万 = 3，200-500 万 = 2，< 200 万 = 1
战略价值：标杆意义 = 3，行业影响 = 2，普通 = 1
扩展潜力：多产品线 = 3，2 产品 = 2，单产品 = 1
```

### 切入难度评分（0-10 分，越高越难）

```
= 竞对壁垒（0-3 分）+ 自建壁垒（0-3 分）+ 决策复杂度（0-2 分）+ 信任缺失（0-2 分）

竞对深度绑定 = 3，浅度使用 = 1，无 = 0
完全自建 = 3，混合 = 1，外采为主 = 0
多层审批 = 2，单一决策人 = 0
无合作历史 = 2，有接触 = 1，已合作 = 0
```

## 阈值（4 象限切分）

| 维度 | 高 | 中 | 低 |
|------|---|---|---|
| 商业价值 | ≥ 7 | 4-6 | ≤ 3 |
| 切入难度 | ≥ 7 | 4-6 | ≤ 3 |

## 在交付物中的应用

在 D1 客户攻坚作战手册中，除了 TOP 排名外，应同时附上矩阵散点图描述，标注每家客户的象限位置。这帮助销售团队理解：

- 为什么某些「排名靠前」的客户反而不应该先打（因为难度太高）
- 为什么某些「排名中等」的客户应该优先（因为是标杆突破口）

D1 客户卡片必须显式标注矩阵象限（① / ② / ③ / ④）。
