# Quality Checklist（L3/L4 深度调研自检清单）

本清单在每批 L3 或 L4 调研完成时由 Agent 自动执行，并写入 `L3_research/quality_check.md` 或 `L4_deep/quality_check.md`。

## L3 模式自检

### 五问完整性

- [ ] 每家公司均回答了 5 个核心问题（参见 [l3-template.md](./l3-template.md)）
- [ ] 升降层建议有具体证据支撑，禁止仅写"维持"无理由
- [ ] 每个结论都带证据强度标签 [F]/[I]/[A]/[E]

### 竞对判定

- [ ] 任何"深度绑定"判定都满足四选二硬证据
- [ ] 不构成降级的弱信号（试用、JD 提及）未被错误升格

### 批量执行

- [ ] 按业务规模指标（AUM/ARR/营收/装机量等）从大到小排序
- [ ] 每批 7-8 家
- [ ] 累计升降层变动超 20% 时已暂停请求人工审核

## L4 模式自检

### 20 维画像

- [ ] 基础信息（8 维）填充率 ≥ 80%
- [ ] 技术栈画像（7 维）填充率 ≥ 80%
- [ ] 商业判断（5 维）填充率 100%
- [ ] 业务规模指标按行业代入正确口径（AUM/ARR/营收/装机量等）

### 证据体系

- [ ] 每个结论字段带 [F]/[I]/[A]/[E] 标签
- [ ] [F]+[I]+[A] 合计 ≥ 80%，[E] ≤ 20%
- [ ] 类比推断（[A]）的基座本身为 [F] 或 [I] 级别
- [ ] 类比推断输出的是区间而非点值
- [ ] 所有信息标注查阅时间或发布时间（参见 [evidence-system.md](./evidence-system.md)）

### 间接推断完整性

- [ ] 第 1 层搜索失败的维度，全部走过第 2-3 层间接推断（参见 [indirect-inference.md](./indirect-inference.md)）
- [ ] 标记 [E] 的维度均记录了已尝试搜索路径

### 矛盾与冲突处理

- [ ] 矛盾因子组合已按矛盾类型标注（参见 [contradictory-signals.md](./contradictory-signals.md)）
- [ ] 多源冲突已按可信度三级体系仲裁
- [ ] 矛盾详情记录表已产出

### 组织窗口监测

- [ ] CTO/核心决策人状态识别（窗口期/固化期/真空期）
- [ ] 三类组织变化信号已扫描（扩张/重组/收缩）

### 横向对比与定性画像

- [ ] 核心发现对比矩阵已产出
- [ ] 每家公司有 150-250 字的定性画像
- [ ] 定性画像四层结构齐备（一句话定义 / 逻辑链 / 反直觉洞察 / 战术建议）
- [ ] 战术建议落到具体可执行动作，无空话
- [ ] 按产品线视角的匹配度分析已产出
- [ ] 优先攻坚路径分级排序已产出

### 客户架构分类（样本 ≥ 10 家时必检）

- [ ] 已归纳本行业 3-6 种架构类型
- [ ] 每种类型有 3-4 个确定性属性
- [ ] 每种类型有"五分钟快速识别指标"
- [ ] 架构类型 → 商业价值映射表已产出
- [ ] 分类覆盖率 ≥ 90%

### 反模式排查

- [ ] 未触发 DR-1 到 DR-12 任何反模式（参见 [anti-patterns.md](./anti-patterns.md)）
