# L4 深度调研模板与执行规范

## 调研深度

每家公司 30-60 分钟搜索量。生成完整技术采购画像，形成攻坚策略。

## 完整 20 维度画像

### 基础信息（11 维）

- 公司名称、公司主体（法定全称）
- 成立时间、注册地址、办公地址（如与注册地址不同则分列）
- 备案号/注册号（如适用行业，采集规范见 deliverable 的 contact-whitelist.md）
- 联系电话 [来源: XXX]、邮箱 [来源: XXX]、官网
- 业务规模指标（按行业代入：AUM/ARR/营收/装机量/用户数）
- 策略类型/业务模式、创始人/核心团队背景
- 员工总数、技术团队规模
- 业务规模指标增速/业务增长态势（按行业代入）

> **联系方式采集**：按 deliverable 的 contact-whitelist.md 四级白名单顺序采集，每条挂来源标签，四级搜不到标 `[需人工核实]`。禁止用大模型默认知识填充。

### 技术栈画像（7 维）

- 算力模式：自建 vs 租用 vs 混合
- GPU 类型与规模
- 云服务商使用情况（哪家、什么服务）
- 大模型使用方式：自研 vs 调用 API vs 微调开源
- 具体使用的模型
- AI 编程工具使用情况
- AI 办公/效率工具

### 商业判断（5 维）

- 产品匹配打分（每个产品 1-10 分 + 理由）
- 竞对渗透深度与风险等级（参见 [l3-template.md](./l3-template.md) 的四选二硬证据法）
- 决策链（谁决策、谁影响、谁执行）
- 预算规模估算（基于团队规模和业务增速推断）
- 攻坚路径建议（从哪切入、先推什么产品、预计周期）

## L4 批量执行规则（两线并行）

- **线路 1**：第一梯队（top 3-5 家）优先深度调研
- **线路 2**：其余 A 层公司分批跟进
- 第一梯队完成后产出对比分析表
- 全量完成后产出综合排序

## 输出格式

每家公司一个 section，结构如下：

```
### 公司名称（层级）

**定性画像：[一句话定义]**

[一段叙事性描述，150-250 字（参见 l4-cross-comparison.md 中的"定性画像一段话描述法"）]

---

[结构化表格：技术架构 / 决策链 / 采购窗口 / 产品匹配 / 竞对态势 / 风险]
```

## 全量产物清单

- Markdown 深度调研报告（每家公司一个 section）
- CSV 对比数据表（20 列宽表）——**编码必须 `utf-8-sig`（UTF-8 with BOM）**，详见 根 SKILL.md「CSV 输出全局硬约束」
- 对比分析文档（横向比较关键差异，参见 [l4-cross-comparison.md](./l4-cross-comparison.md)）
- **客户架构分类模型**（当样本 ≥ 10 家时产出：分类表 + 快速识别速查表 + 商业价值映射）

## 输入与输出依赖

- **上游输入**：L3 升降层判定（最终 A 层名单）+ L2 全量数据
- **下游输出**：L4 深度调研产物，作为 deliverable 生成最终交付物的依据

## 质量门槛

- 每家公司 20 维度填充率 ≥ 80%
- 证据强度标签（[F]/[I]/[A]/[E]）填充率 100%
- 决策链至少识别核心 1 人（CTO/CIO/CEO 或对应角色）
- 攻坚路径建议必须落到具体可执行动作（"通过 XX 渠道触达 YY 角色"），禁止"建立关系"等空话
