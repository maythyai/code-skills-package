# 差异化定位三支点模型

在高度竞争的市场中，不追求"全面优于对手"，而应建立三个差异化支点形成稳定的"铁三角"定位。

## 三支点框架

| 支点 | 定义 | 诊断问题 | 示例 |
|-----|------|---------|------|
| **生态锚点** | 与目标客户群的技术生态建立有机连接 | "客户的技术社区中，我方有哪些天然优势？" | 开源社区影响力、行业标准参与、技术联盟 |
| **架构适配** | 承认客户现状，提供"插入式"而非"替换式"方案 | "客户现有架构是什么？如何嵌入而非颠覆？" | 混合部署支持、API兼容、渐进迁移路径 |
| **行业纵深** | 对目标行业的深度理解形成的独特价值 | "我方在该行业有哪些竞对不具备的积累？" | 行业模型预训练、垂直场景解决方案 |

## 支点诊断与选择

在 Phase 1（快筛）之前，应完成以下自检：

```
对目标行业的三支点评估：
├─ 生态锚点：[强/中/弱] — 具体依据是什么？
├─ 架构适配：[强/中/弱] — 客户主流架构与我方兼容度？
└─ 行业纵深：[强/中/弱] — 行业案例/模型/方案积累？

至少 2 个支点为"中"以上 → 可启动调研
3 个支点均为"弱" → 建议暂缓，先补齐短板
```

## 定位指导后续调研

三支点评估结果直接影响后续 L2-L4 的调研重点：

- **生态锚点强** → L2 阶段侧重扫描"已在我方生态中"的客户
- **架构适配强** → L3 阶段侧重验证"技术架构兼容性"
- **行业纵深强** → L4 阶段侧重深挖"行业特有痛点匹配"
