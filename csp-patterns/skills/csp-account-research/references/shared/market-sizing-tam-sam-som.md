# 市场规模分解与瓶颈识别（TAM/SAM/SOM）

在 Phase 1 完成后（知道行业有多少家公司），应进行市场规模的三层分解，识别战略瓶颈。

## 三层分解框架

```
TAM（总可寻址市场）
 └─ 计算方式：行业总规模 × IT投入比例
    └─ 回答：这个行业IT市场有多大？

SAM（可服务市场）
 └─ 计算方式：TAM × 新技术相关支出占比
    └─ 回答：其中与我方产品相关的有多大？

SOM（可获得市场）
 └─ 计算方式：SAM × 实际渗透率
    └─ 回答：我方实际能拿到多少？
```

## 瓶颈诊断

关键不在于算出绝对数字，而在于**识别从 TAM→SAM→SOM 的转化瓶颈在哪**：

| 瓶颈位置 | 含义 | 战略应对 |
|---------|------|---------|
| TAM→SAM 转化率低 | 行业 IT 投入集中在传统方向，新技术渗透慢 | 侧重"教育市场" + 标杆案例 |
| SAM→SOM 转化率低 | 产品能服务但客户不选我方 | 侧重"竞争差异化" + 信任建设 |
| TAM 本身小 | 行业规模有限 | 评估是否值得投入，或寻找跨行业复用 |

## 瓶颈决定资源配置

```
如果瓶颈在"信任渗透率"（SAM→SOM 转化率<5%）：
  → 60% 资源投入案例建设和关系维护
  → 30% 资源投入产品适配
  → 10% 资源投入新客户拓展

如果瓶颈在"技术渗透率"（TAM→SAM 转化率<30%）：
  → 50% 资源投入行业教育和市场影响力
  → 30% 资源投入产品行业化适配
  → 20% 资源投入已有需求客户转化
```

## 与调研流程的衔接

- Phase 1（快筛）完成后：初步估算 TAM 和 SAM
- Phase 2（信号扫描）完成后：根据 A/B/C 层分布修正 SOM 预期
- Phase 4（深度调研）完成后：根据实际 deal size 回溯验证市场规模估算
