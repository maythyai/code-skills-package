# Phase 1：L1 初始池构建

## 目标

从行业数据库、榜单、协会名录、公开排名等构建初始公司池，为后续 L2 信号扫描提供输入。

## 执行步骤

1. **公司池来源选择**（按 brief.json 中的 industry_name 选取）：
   - 行业协会会员名单
   - 监管机构注册名录
   - 第三方排名榜单（按规模/营收/AUM）
   - 财经媒体年度盘点
   - 行业专属数据库
   - **需求反推补充入池**（防止遗漏非头部高匹配客户）：
     上述 5 条来源天然偏向行业头部。为覆盖"知名度不高但需求强烈"的中腰部公司，额外从以下渠道反向入池：
     - 招投标平台反查：搜索近 12 个月内发布过 AI / 云计算 / 大模型相关招标的公司（chinabidding.com / 政府采购网 / 行业垂直招标平台）
     - 垂直招聘平台反查：在 BOSS 直聘/拉勾/LinkedIn 按"AI 工程师 + 目标行业"筛选，提取正在招聘 AI 岗位但不在上述榜单中的公司
     - 我方已有线索导入（需用户配合）：从我方 CRM / 试用客户库中导入"已试用未深度合作"的目标行业客户
     - 技术社区/开源生态反查：在 GitHub、技术论坛、行业垂直社区中搜索目标行业公司的技术输出
   
   **需求反推执行规则**：
   - 此路径为标准入池路径的补充，不替代前 5 条
   - 通过此路径入池的公司在 L1_pool.csv 中标注 `入池来源=需求反推`
   - 快筛规则同样适用（规模过小/地域不符仍剔除）
   - 建议占总池比例 15-30%，避免过度依赖单一来源

2. **信息抓取**：
   - 公司名称（中英文 + 法定全称）
   - 基础属性（业务规模指标、地域、成立时间、行业细分）
   - 业务规模指标按行业代入：AUM（私募/资管）、ARR（SaaS）、营收（通用）、装机量（制造）、用户数（互联网）

3. **快筛规则**：按用户在 brief.json 中定义的硬门槛剔除不符合条件的公司，例如：
   - 规模太小（低于规模阈值）
   - 地域不符
   - 业务方向偏离

4. **名单质量校验**（强制步骤）：
   - 通过工商注册系统（天眼查/企查查或对应行业注册库）逐一确认公司法定名称
   - 确保 L2 搜索不会因名称错误导致大面积失败
   - 已注销/已合并的公司在此阶段标记或剔除
   - 重复条目去重

## 产物

`L1_pool.csv`，字段建议：

| 字段 | 说明 |
|---|---|
| 公司名称 | 法定全称 |
| 简称/常用名 | 用于搜索的备用名 |
| 英文名 | 跨境/外资公司必填 |
| 业务规模指标 | 按行业代入 |
| 地域 | 总部所在地 |
| 成立时间 | 用于判断成立年限 |
| 行业细分 | 用于分群 |
| 工商状态 | 在营/注销/吊销 |
| 备注 | 名称校验中发现的问题 |

## 完成标准

- [ ] L1_pool.csv 已写盘
- [ ] 工商名称校验完成率 100%
- [ ] 已注销/已合并公司已剔除或标记
- [ ] 重复条目已去重
- [ ] 总数符合 brief.json 中的预期规模
- [ ] 需求反推路径至少贡献 3 家以上非榜单来源公司（若该路径确实无法补充到公司，在 CHANGELOG 中记录原因）
