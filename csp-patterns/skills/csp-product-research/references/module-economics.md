# 商业经济验算 — 执行步骤

> 独立使用时的完整执行流程。数据质量规则见 [data-quality-rules.md](data-quality-rules.md)，方法论参考见 [methodology.md](methodology.md)。（同目录下的参考文件）

## 前置确认

1. **商业模式描述**：卖什么？卖给谁？怎么收费？
2. **已知信息**：客单价 / 获客成本 / 留存率 / 毛利率（有多少给多少，没有的AI估算）
3. **团队规模与成本**：团队人数、年固定成本（如不知道则AI估算）

## 执行流程（AI 自主完成）

### Step 1：定价分析

- **竞品定价全景**：搜索同类产品定价，建立参考基准
- **Van Westendorp 简化四问**建议区间：
  - 太便宜不敢用（怀疑质量）
  - 划算（性价比高）
  - 贵但能接受
  - 太贵不考虑
- **定价模式建议**：SaaS订阅/用量付费/年框/混合

### Step 2：单位经济模型

**核心参数（三情景：乐观/中性/悲观）：**

| 参数 | 说明 |
|------|------|
| ACV（客单价） | 年合同价值 |
| 毛利率 | 中国SaaS基准50-70% |
| 客户留存年数 | 平均客户生命周期 |
| NRR | 净收入留存率（中国基准95-110%） |
| CAC | 获客成本 |

**核心计算：**
- **LTV** = ACV × 毛利率 × 平均留存年数
- **LTV/CAC** = 客户终身价值 ÷ 获客成本（基准 ≥ 3:1）
- **CAC回收期** = CAC ÷ (ACV × 毛利率 / 12)（中国基准12-24月）

**高幻觉数字警告：** CAC和NRR是高幻觉数字，无可靠来源必须标注为D级。

### Step 3：最小可行规模

- **团队配置假设** + 年固定成本估算
- **最小客户数** = 年固定成本 ÷ 客单价
- **获客漏斗**：按渠道转化率，需要多少潜在用户才能获得这些客户？
- **可行性判断**：这个数字在市场中是否现实？

### Step 4：贡献边际分析

- 单客户收入
- 单客户可变成本（云资源/服务/客户成功/数据处理）
- 贡献边际 = 收入 - 可变成本
- 哪些客户群贡献边际最高？

### Step 5：成本结构

- 研发 / 销售 / 运营 / 云资源 各项占比
- AI推理成本细算（如适用）
- 随客户增长的边际成本变化

### Step 6：收入预测（3年）

| 指标 | Year 1 | Year 2 | Year 3 |
|------|--------|--------|--------|
| 付费客户数 | | | |
| ARR | | | |
| 毛利率 | | | |
| 累计投入 | | | |
| 累计收入 | | | |
| 覆盖率 | | | |

**收入对成本规则：** 第3年覆盖率低于100%标为高风险。

### Step 7：敏感性分析

- 哪个参数变化对结果影响最大？（客单价/CAC/留存率/毛利率）
- 该参数的安全边际有多大？

## 报告结构

```markdown
# {商业模式} — 经济验算报告

## 核心结论（经济模型是否成立 + 前提条件 + 置信度）
## 一、定价分析（竞品定价 + Van Westendorp区间 + 定价模式建议）
## 二、单位经济模型（LTV/CAC/回收期 三情景）
## 三、最小可行规模（最少客户数 + 获客漏斗 + 可行性判断）
## 四、贡献边际（单客户经济 + 客户群排序）
## 五、成本结构
## 六、3年收入预测（三情景 + 覆盖率）
## 七、敏感性分析（最敏感参数 + 安全边际）
## 附录（假设清单 + 数据来源）
```

## 交互原则

- AI 自主搜索定价benchmark和行业数据
- 所有假设显式标注，用户可调整参数重新计算
- 经济模型不成立时，主动建议调整定价/模式/客群
