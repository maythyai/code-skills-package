# 行业/赛道全景扫描 — 执行步骤

> 独立使用时的完整执行流程。数据质量规则见 [data-quality-rules.md](data-quality-rules.md)，方法论参考见 [methodology.md](methodology.md)。（同目录下的参考文件）

## 前置确认

1. **行业/赛道名称**（一句话描述）
2. **关注角度**：全面了解 / 投资视角 / 寻找切入点 / 跟踪趋势
3. **输出形态**：要点摘要 / 完整报告

## 执行流程（AI 自主完成，15-30 分钟）

### Step 1：品类阶梯定位

画出行业品类阶梯，确定全景层和深潜层。

### Step 2：市场规模

- **TAM/SAM/SOM 三层估算**（自上而下 + 自底向上交叉验证）
- **增长趋势**：CAGR + 驱动因素
- **市场阶段**：萌芽 / 成长 / 成熟 / 衰退

### Step 3：产业链图谱

- 上中下游结构 + 各环节利润率
- 关键玩家标注（角色 + 关系）
- 利润池分布：哪个环节赚最多钱？

### Step 4：竞争格局

- **四层覆盖**：直接玩家 / 间接替代 / 平台级 / 隐形传统
- Top 5-8 玩家简档（一句话定位 + 核心优势 + 规模）
- **Porter 五力**评估（每力 1-5 分）
- 行业集中度和竞争态势

### Step 5：趋势与时机

- **Why Now 分析**：技术/政策/行为/供给变量
- **跨越鸿沟**定位：市场在哪个阶段？
- 未来 3 年关键趋势预判

### Step 6：政策环境（如涉及政策驱动市场）

- 顶层政策 + 实施细则 + 地方进展
- 时间表 + 资金机制
- 统一平台约束

### Step 7：机会与风险

- **机会地图**：哪些细分领域/环节有结构性机会？
- **风险清单**：哪些因素可能导致行业下行？
- 机会与风险数量对等（强制平衡）

## 报告结构

```markdown
# {行业名称} — 全景扫描报告

## 核心发现（3-5 句话）
## 一、市场规模与增长（TAM/SAM/SOM + 增长趋势 + 市场阶段）
## 二、产业链（图谱 + 利润分布 + 关键玩家）
## 三、竞争格局（四层覆盖 + Top玩家简档 + Porter五力）
## 四、趋势与时机（Why Now + 跨越鸿沟 + 未来3年趋势）
## 五、政策环境（如适用）
## 六、机会与风险（机会地图 + 风险清单）
## 附录（数据溯源表 + 来源索引）
```

## 交互原则

- AI 自主完成全部调研，用户不参与搜索过程
- 输出后用户可要求深入某个章节
- 如发现值得做方向评估的切入点，主动建议进入完整流程
