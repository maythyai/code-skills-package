# 深度调研报告结构模板（完整流程 Phase 1 产出）

```markdown
# {方向名称} — 深度调研报告

## 〇、核心结论
  结论类型 + 判断先行 + 核心理由（一句数据）+ 下一步行动
  综合置信度（A/B/C/D）

## 一、市场规模与趋势
  1.1 TAM/SAM/SOM（自上而下+自底向上交叉验证）
  1.2 产业链图谱（上中下游+利润率+关系标注）
  1.3 市场交付模式
  1.4 时机判断（Why Now + 跨越鸿沟）

## 二、竞争格局
  2.1 品类阶梯 + 四层竞品地图
  2.2 核心竞品五要素深潜 + 关系标注
  2.3 Porter 五力
  2.4 蓝海战略画布
  2.5 竞品共同弱点

## 三、客户洞察
  3.1 市场细分（STP）
  3.2 核心 JTBD
  3.3 现有方案与切换成本
  3.4 购买决策链

## 四、团队-方向匹配
  4.1 VRIO 评估
  4.2 创始人-市场契合度
  4.3 能力缺口矩阵

## 五、经济模型
  5.1 定价参考
  5.2 单位经济模型（LTV/CAC 三情景）
  5.3 最小可行规模
  5.4 数据壁垒构建路径
  5.5 3 年收入预测

## 六、增长路径
  6.1 AARRR 漏斗
  6.2 获客渠道
  6.3 增长飞轮

## 七、风险评估
  7.1 风险矩阵（概率×影响×可控性）
  7.2 反方辩手自检
  7.3 信息缺口清单

## 附录
  A. Lean Canvas 初版
  B. 数据溯源表
  C. 自检清单执行记录
  D. 数据来源索引
```

## 报告规范

- **结论先行**：每章第一句话是核心结论，方便快速浏览
- **强制反证**：每章至少1条反面证据，避免确认偏差
- **术语规则**：正文用直白中文，不堆方法论名称，降低认知负荷
- **中国 benchmark 优先**：国内数据更具参考价值，海外数据仅作对比
