# 业务术语库使用指南

## 概述

业务术语库帮助测试技能理解行业专业术语：遇到不熟悉的术语时查询本库，获得业务场景说明与
同义词别名，从而提高元素定位的准确性（先按术语/别名找标签，再找邻近输入框）。

## 文件结构

```
terminology/
├── business-terms.json    # 主术语库
└── README.md              # 本说明
```

## 条目格式

```json
{
  "术语名称": {
    "user_scenario": "用户在什么场景下会接触这个术语",
    "aliases": ["同义词1", "英文对照", "简称"],
    "notes": "数据格式、常见取值或特殊注意事项"
  }
}
```

- **user_scenario**：业务场景描述，帮助理解术语含义
- **aliases**：同义词/中英文对照/简称/全称，用于扩展定位匹配
- **notes**：数据格式、常见取值、定位注意事项

## 使用方法

1. 测试步骤出现不熟悉术语时，在 `business-terms.json` 搜索术语名
2. 没有直接匹配则搜 `aliases`
3. 读 `user_scenario` 理解业务含义
4. 参考 `notes` 获取格式/取值信息
5. 定位策略：优先找含术语文本的标签 → 备选找别名标签 → 在术语所属业务区域定位输入框

## 维护原则

1. **业务导向**：只描述业务场景，不涉及技术实现
2. **用户视角**：从用户使用角度描述
3. **别名完整**：尽量收齐中英文/简称/全称
4. **持续扩充**：按项目实际遇到的新术语不断补充
5. **领域隔离**：同一术语在不同业务领域可能有不同含义，用条目名区分（如 `订单状态` vs `退款状态`）

## 添加新术语

```json
{
  "新术语": {
    "user_scenario": "详细描述用户在什么业务场景下使用这个术语",
    "aliases": ["同义词", "英文对照", "简称"],
    "notes": "数据格式、常见取值或特殊说明"
  }
}
```

> 术语库随项目演进。把测试过程中反复出现、定位困难的行业术语沉淀到这里，让后续用例与
> 团队成员都能复用，是经验学习系统的语义补充。
